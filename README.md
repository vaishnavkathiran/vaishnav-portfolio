# Vaishnav Kathiran — Portfolio Website

A responsive, animated single-page portfolio built with HTML, CSS and vanilla JavaScript. Includes hero entrance effects, floating data card and tags, rotating orbit graphics, animated chart bars, and scroll-triggered section reveals. Respects reduced-motion accessibility preferences.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a browser.

## Personalize before publishing
In `index.html`, replace:
- `YOUR_EMAIL@example.com`
- `https://www.linkedin.com/in/YOUR-LINKEDIN/`
- `https://github.com/YOUR-GITHUB/`

Add links to your actual project repositories and demos. Review the project descriptions and experience details for accuracy before publishing.

## Publish free with GitHub Pages
1. Create a GitHub repository (for example, `vaishnav-portfolio`).
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. GitHub will provide your public website URL.
